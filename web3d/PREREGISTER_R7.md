# 7회차 사전 등록 — 연기 positive를 조리 규모로 재조정

작성 2026-08-04, **합성 및 학습 이전에 확정.** 이후 수정 금지.

## 6회차가 남긴 진단

조리 연기 평가군 E(179장)를 만들어 재보니 인식률 11.7%, 수증기와의 판별비 **0.54**였다.
1 미만은 잡아야 할 연기보다 무시해야 할 김에 더 자주 반응한다는 뜻이다.
정탐 21장이 영상 3개에 몰렸고 14개 중 10개가 0%였으며, 반응한 영상은 모두 굵고 진한
연기 기둥이었다.

**smoke 클래스가 배운 것은 "조리 연기"가 아니라 "크고 진한 회색 덩어리"다.**
6회차 합성 연기의 폭이 조리기구 대비 0.45~1.25배였고, 실제 조리 연기는 그보다 좁고
가늘게 오른다. 수증기 평가군은 김을 클로즈업한 진한 덩어리라 오히려 합성 연기와 닮았다.

## 이번 회차가 바꾸는 것

**가설: positive 분포가 대상을 대표하지 못해 판별비가 뒤집혔다.**

- 합성 연기 폭을 조리기구 대비 **0.25~0.80배**로 축소(6회차 0.45~1.25), 세로 신장 확대
- 경계 블러 축소(0.2~1.0) — 실 구조를 남긴다
- 소재 추출의 밀도 게이트 완화(p99.5 0.45→0.28, std 0.13→0.07) — 얇은 실연기 유형 보존.
  **197종 → 248종**, 특히 가는 연기 영상(smoke12 3→23, smoke15 0→11, smoke18 15→35)이 살아남음
- 이 형태를 전체 연기 장면의 **70%**에 적용

**불투명도와 가시성 검사는 6회차 그대로 둔다.** 초기 시도에서 알파까지 낮추자 급식실
배경에서 연기가 보이지 않는 장면이 대량 생성됐다. 라벨만 있고 신호가 없는 예제는
학습에 해롭다.

**수증기 negative는 이번 회차에 넣지 않는다.** positive가 대상을 대표하지 못하는 상태에서
hard negative를 넣으면 2회차(주황 물체 → 정탐 붕괴)를 반복한다. 순서는 positive 교정이 먼저다.

엄밀히는 코드 변경이 두 곳(소재 게이트, 합성 크기)이다. 둘 다 "positive를 조리 규모로

않는다. 이 점을 한계로 기록한다.

## 판정 기준

운용 임계값 **conf 0.10**, 평가군 E(조리 연기 179장) / D(수증기 352장).

| 지표 | 기준 |
|---|---|
| **판별비 E/D** | **≥ 1.0 성립** / 0.7~1.0 개선했으나 미달 / < 0.7 실패 |
| E 조리 연기 인식률 | 참고 기록 (판별비의 분자) |
| A-fire 화염 인식률 | 6회차(30.7%) 대비 **8%p 초과 하락 시 회귀** — 되돌림 검토 |
| B 급식실 오탐률 | ≤ 15% |

주 지표를 인식률이 아니라 **판별비**로 둔다. 연기만 잘 잡아도 김을 같이 잡으면 배치할 수
없고, 반대로 둘 다 안 잡으면 조기 경보가 성립하지 않기 때문이다.

## 미리 밝혀 두는 해석 규칙

- **판별비 1 미달 시 단일 프레임 접근의 한계로 판단하고 다중 프레임 설계 검토로 넘어간다.**
  김과 연기는 둘 다 회색 반투명 부유물이며, 결정적 단서는 시간 변화(김은 일정, 과열 연기는
  점점 짙고 어두워짐)에 있을 가능성이 높다. 이 경우 본 PoC 범위를 넘는다.
- E는 스톡 영상이며 급식실이 아니다. 그릴·철판 93장 / 스토브 86장으로 유형은 반반이나
  급식실 튀김솥과는 여전히 거리가 있다.
- 어떤 결과가 나오든 E·D·판별비·A-fire·A-smoke·B·C를 모두 공개한다.
- 6회차 판별비 0.54를 기준선으로 명시하고, 개선폭을 함께 보고한다.
